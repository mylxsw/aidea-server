# 外部支付测试

在 `aidea-server` 目录执行：

```bash
./scripts/test-external-pay.sh
```

脚本启动独立的临时 MariaDB 容器，执行支付模块测试、旧支付金额解析测试和全量构建，结束后删除容器。每个功能测试还会单独建立并清理自己的数据库，避免通知任务跨测试领取订单。GitHub Actions 中的 `External payment tests` 工作流使用同一命令。

| 测试范围 | 验证内容 |
| --- | --- |
| 请求安全 | JWT 验签、请求路径和内容绑定、过期、重放、跨应用订单访问、非法回调地址 |
| 下单和状态 | 实际 HTTP 下单、重复下单幂等、参数冲突、金额不符、待支付单关闭、两种渠道使用独立回调地址 |
| 支付宝回调 | 用测试 RSA 密钥生成真实签名；验证验签、应用身份、金额、重复回调和数据库入账 |
| 微信回调 | 用测试证书签名并以 AES-GCM 加密通知；验证验签、解密、商户身份、金额、重复回调和数据库入账 |
| 通知与补漏 | 真实 HTTPS 测试接收端、通知签名、首次失败后的重试、事件幂等、动态回调地址、渠道回调缺失后的主动查单、分页查询 |
| 数据库 | 迁移、订单和通知同一事务提交、重复支付不重复生成事件 |

这些测试不连接微信或支付宝的真实网关，也不会产生实际扣款。正式开启前，仍需在测试或生产商户环境各完成一笔小额支付宝和微信支付，核对渠道订单、AIDEA 订单、接入应用通知及原有 AIDEA 充值流程。
